iPhone / 离线 / 部署说明

推荐：把整个文件夹放到 GitHub Pages / Cloudflare Pages / Netlify（免费、HTTPS），手机 Safari 打开网址即可；定位与 Yelp 外链需要能上网。

内网电脑 + 手机：电脑在项目目录运行 python3 -m http.server 8765，手机连同一 Wi‑Fi，浏览器打开 http://电脑IP:8765（不要用仅 file:// 打开，地图数据可能加载失败）。

离线数据：修改 data/places.json 后在本机执行 python3 scripts/embed_places.py 更新 embedded-places.js；当无法读取 json 时会自动用内嵌数据。

纯原生 iOS App：本仓库是网页，若要 App Store 离线包需用 Xcode + WKWebView（如 Capacitor）自行打包，成本较高。
